# Hell Archive Prototype

Minimal browser-based gameplay experiments for a solo-developed 1962 political deduction mystery set in an infernal bureaucracy.

## Play locally
Open `index.html` in Chrome, Firefox, or Edge. There is no build step, backend, installation, external dependency, or Godot requirement.

## Publish with GitHub Pages
Repository **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. Then the URL should be `https://dangkhanhke-ui.github.io/hell-archive-prototype/` once GitHub Pages finishes publishing. This setting has **not** been activated or verified by the assistant.

## What v0.1 tests
Can a player distinguish *what the archive proves* from *what it does not prove about an individual*? One tiny case, three documents, one conclusion. It deliberately **does not** validate long-term replayability, interrogation, authentic card-machine mechanics, or the nine circles.

## Collaboration
Open Issues for observations from testers. Future gameplay changes should be built in small PRs. Friends can fork and submit PRs, or the owner can grant collaborator access via GitHub Settings → Collaborators.

## Safety and scope
Public repository: don't commit private story notes, secrets, credentials, or personal data. Everything in this prototype is fictional. No analytics, account login, or tracking. Prior prototypes and unrelated repositories were not touched.
